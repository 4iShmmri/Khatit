# Khatit — تطبيق الملاحة الصحراويّ السعوديّ

تطبيق iOS يعمل بدون إنترنت تمامًا، يُغطّي المملكة العربيّة السعوديّة بكامل تضاريسها وطرقها وقراها وآبارها وودياتها.

## الإصدارات

ملفّات البيانات الكبيرة (الخريطة، التضاريس) تُوزَّع عبر **GitHub Releases** ليبقى حجم التطبيق الأوّليّ على App Store أصغر، ويُنزّلها التطبيق عند الحاجة:

- **Khatit Terrain v1** — بيانات الارتفاع (~75 MB) لإظهار التضاريس ثلاثيّة الأبعاد

كلّ release يحوي ملفّ `.sha256` للتحقّق من سلامة التنزيل.
